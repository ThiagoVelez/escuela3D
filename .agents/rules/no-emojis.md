# Regla: Cero Emojis y Optimización Ligera

1. **PROHIBIDO EL USO DE EMOJIS**: NUNCA usar caracteres emoji. Se deben utilizar exclusivamente iconos (Lucide React o SVG nativos).
2. **OPTIMIZACIÓN DE RECURSOS**: Evitar la carga de entornos 3D o Canvas WebGL pesados. Usar interfaces 2D elegantes, visualizadores SVG dinámicos y componentes ligeros.
3. **RESPONSIVE DESIGN**: Asegurar compatibilidad fluida en teléfonos móviles, tablets y monitores de escritorio.
